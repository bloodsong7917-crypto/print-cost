# Себестоимость 3D-печати

Калькулятор себестоимости деталей для 3D-печати и учёт готовых моделей. Работает на Android и Windows, без интернета и без аккаунта.

## Скачать

**[Последняя версия →](https://github.com/bloodsong7917-crypto/print-cost/releases/latest)**

- **Android** — файл `PrintCost-….apk`. При установке телефон попросит разрешить установку из неизвестных источников.
- **Windows** — файл `PrintCost-portable-….exe`, запускается без установки. SmartScreen покажет предупреждение: «Подробнее» → «Выполнить в любом случае».

**Веб-версия:** <https://bloodsong7917-crypto.github.io/print-cost/> — открывается в браузере, её можно установить как приложение (в Chrome: меню → «Установить приложение»).

## Возможности

- Расчёт себестоимости по весу пластика и времени печати, с учётом электричества, амортизации принтера и запаса на брак.
- Профиль: типы пластика с ценой за 1 кг.
- Учёт деталей: артикул, название модели, себестоимость, вес 1 шт; поиск, редактирование, экспорт в CSV.
- Заметки.
- Резервная копия в файл и восстановление из него — так же данные переносятся между телефоном и компьютером.

Все данные хранятся только на устройстве и никуда не отправляются.

## Сборка

Приложение — это веб-страница из папки `www/`, упакованная в Capacitor (Android) и Electron (Windows).

```bash
./build.sh          # .apk и .exe
./build.sh android  # только .apk
./build.sh win      # только .exe
```

Скрипт ждёт Node.js, JDK 21 и Android SDK в папке `~/print-cost-build-tools` (подпапки `node`, `jdk`, `android-sdk`); другой путь задаётся переменной `PRINT_COST_TOOLS`. Готовые файлы появляются в `dist/`.
